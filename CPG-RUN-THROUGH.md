# Academy of Medicine CPG run-through for the Green Zone guide

Page: **Clinical Practice Guidelines**, Academy of Medicine of Malaysia (https://www.acadmed.org.my/index.cfm?&menuid=67), read on 9 November 2026. It lists 109 CPGs in 21 specialty sections. For each it gives the year and a link to the CPG, and where there is one, a Quick Reference (QR), a Training Module (TM) and a Patient Information Leaflet (PIL).

Krishna asked on 9 Nov 2026 to run through the site, review the CPGs and add what the Green Zone needs, interactive and premium. This page places every CPG on the list and says why. The first pass placed them from the list itself, the app's pathways and the ebook's references; once Krishna supplied all 109 PDFs the same day, each was checked against its own front matter (copyright and reuse terms, edition, what it replaces, and the chapters an ED doctor would use), and 18 moved tier. The CPGs built into the guide were then reviewed line by line.

## How a CPG goes into the app

- The ebook stays the approved source (rule 5). A CPG goes in only when Krishna admits it (rule 8), as the dengue CPG was on 9 Nov 2026: quoted as printed, with its page and the publisher's acknowledgement, in its own Guideline entry beside the ebook pathway (`grp:'cpg'`), never replacing it. Where the two differ, the difference becomes an open item.
- Each CPG's copyright page decides whether it can be quoted. Of the 109, 73 allow reproduction with acknowledgement, unchanged; 34 state no terms; 2 reserve all rights (the Reuse column below). Only the first kind can be built into the guide without the publisher's permission.
- Each one chosen gets the same line-by-line review as the dengue CPG, from its PDF, with the review kept in a file like `CPG-REVIEW.md`.

## The PDFs

- Every file link on the Academy's page opens a Cloudflare check (a CAPTCHA), which Claude may not complete, and the Ministry of Health's CPG page refused an automated request (HTTP 403). The asthma and gout PDFs came from MaHTAS's own file host (mymahtas2.moh.gov.my).
- Krishna then supplied all 109 PDFs in one folder, with a manifest of each file's source, pages and SHA-256, and the same set in a Google Drive folder that anyone with the link can view (https://drive.google.com/drive/folders/1gzMDT4vyUnK-WiyC2AKdIAEP2eFjxjwh).
- In the app, a shelf card opens the Drive copy only where the CPG's terms allow reproduction; otherwise it links to the Academy's own file.

## How the chosen CPGs would look

- The dengue CPG pattern, which Krishna approved: a Guideline entry beside its pathway, with a stepper for the ED decision, reference tabs quoted with pages, calculators where the CPG gives numbers, and the CPG's patient leaflet where it has one.
- Infographics drawn in the page, at no data cost: severity ladders, the whole-pathway map and the zone map, extended rather than replaced.
- A banner for each entry with its own Flow Studio still (free) and 8-second loop (12 credits each), with Krishna's go-ahead for that job (rule 2).
- Page weight: the dengue CPG round took the page from 481 KB to 550 KB (its data alone is 46 KB, 16 KB compressed). Six entries of that size would take it to about 950 KB, about 290 KB compressed. As built (9 Nov 2026), the six entries, the shelf and three calculators took it to 826 KB, 256 KB compressed. Past about 1 MB, each CPG's text would load only when its entry is opened.
- A narrated infographic film per CPG (HyperFrames, with a VoiceStudio voice) only if Krishna asks for it once the entries exist; each film is 3 to 4 MB to watch.

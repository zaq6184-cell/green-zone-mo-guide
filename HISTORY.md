# Green Zone MO Guide: history

Moved from `CLAUDE.md` on 10 Nov 2026, so that the instructions every session loads stay short. Each round is as recorded at the time, oldest first: where two rounds describe the same feature, the later one is current, and `CLAUDE.md` holds the present state and the rules. Record each new round here. Like `CLAUDE.md`, this file is public once pushed.

## The rounds

- **Calculators** (live since 9 Nov 2026, artifact version 1794163133-e657 and the public web app): a Calculators view (`#calc`) replaces Quick sums. The six group tiles carry Flow Studio stills and loops (`kids`, `doses`, `scores`, `calm`, `head`, `dengue`).
